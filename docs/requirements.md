# Personal Finance Tracker

## Objetivo

Aplicación web para gestionar finanzas personales, permitiendo registrar ingresos y gastos, visualizar estadísticas y administrar presupuestos mensuales.

## Funcionalidades MVP

- Registro de usuarios.
- Inicio de sesión.
- Registrar ingresos.
- Registrar gastos.
- Crear categorías.
- Dashboard financiero.
- Presupuestos por categoría.
- Estadísticas mensuales.
