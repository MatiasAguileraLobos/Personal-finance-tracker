# Personal Finance Tracker

## Objetivo

Aplicación web para gestionar finanzas personales, permitiendo registrar ingresos y gastos, visualizar estadísticas y administrar presupuestos mensuales.

---

# Alcance del proyecto

La aplicación permitirá a los usuarios:

- Crear una cuenta e iniciar sesión.
- Registrar ingresos y gastos.
- Organizar transacciones mediante categorías.
- Crear presupuestos mensuales por categoría.
- Consultar estadísticas y gráficos financieros.
- Visualizar un resumen de su situación financiera.

---

# Funcionalidades MVP

## Gestión de usuarios
- Registro de usuarios.
- Inicio de sesión.
- Cierre de sesión.
- Edición de perfil.

## Gestión de transacciones
- Registrar ingresos.
- Registrar gastos.
- Editar transacciones.
- Eliminar transacciones.
- Consultar historial de transacciones.
- Filtrar transacciones por fecha.
- Filtrar transacciones por categoría.

## Gestión de categorías
- Ver categorías por defecto.
- Crear categorías personalizadas.
- Editar categorías personalizadas.
- Eliminar categorías personalizadas.

## Gestión de presupuestos
- Crear presupuestos mensuales.
- Editar presupuestos.
- Ver porcentaje utilizado.
- Mostrar alertas cuando un presupuesto sea superado.

## Dashboard financiero
- Ver balance total.
- Ver ingresos del mes.
- Ver gastos del mes.
- Ver últimas transacciones.
- Ver gastos por categoría.
- Ver evolución mensual.

## Requisitos no funcionales

- La aplicación deberá ser responsive.
- Las contraseñas deberán almacenarse cifradas.
- Cada usuario solo podrá acceder a sus propios datos.
- La aplicación deberá funcionar en los principales navegadores modernos.
- El sistema deberá validar los datos ingresados por el usuario.
