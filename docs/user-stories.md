# User Stories

- Como usuario, quiero registrar un gasto para llevar el control de mi dinero.
- Como usuario, quiero registrar un ingreso para conocer mi balance.
- Como usuario, quiero crear presupuestos para evitar gastar de más.
- Como usuario, quiero ver gráficos para entender en qué gasto más.
- Como usuario, quiero consultar mi balance mensual rápidamente.
